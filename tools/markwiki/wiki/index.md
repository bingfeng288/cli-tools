# Welcome to MarkWiki

This is your personal knowledge base. Write in **markdown** and organize your thoughts.

## Quick Start

- Create new pages with the `+ New Page` button
- Link pages together with `[[wiki links]]`
- Use `Ctrl+K` to search across all pages
- Press `Ctrl+S` to save while editing
