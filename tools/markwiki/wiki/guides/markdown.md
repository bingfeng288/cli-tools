# Markdown Reference

A quick reference for markdown syntax supported in MarkWiki.

## Text Formatting

- **Bold** with `**text**`
- *Italic* with `*text*`
- `Code` with backticks
- ~~Strikethrough~~ with `~~text~~`

## Headers

```markdown
# H1
## H2
### H3
```

## Lists

Unordered:
- Item 1
- Item 2
  - Nested item

Ordered:
1. First
2. Second
3. Third

## Code Blocks

```javascript
function hello(name) {
  console.log(`Hello, ${name}!`);
}
```

## Blockquotes

> This is a blockquote.
> It can span multiple lines.
