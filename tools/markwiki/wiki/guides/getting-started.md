# Getting Started

Welcome! This guide will help you get the most out of MarkWiki.

## Creating Pages

You can create pages in two ways:

1. Click the **+ New Page** button in the sidebar
2. Use a [[wiki link]] to a non-existent page, then click it

## Organizing with Folders

Use slashes in the page path to create folders:

- `notes/meeting-2024-01` → creates a `notes` folder
- `projects/my-app/setup` → nested folders

## Wiki Links

Connect pages with double brackets:

```
[[page-name]]           → links to page-name
[[folder/page|Display]] → links with custom text
```

See also: [[guides/markdown|Markdown Reference]]
